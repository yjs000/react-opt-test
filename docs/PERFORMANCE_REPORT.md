- **최적화 React 지표**는 같은 검색 교체를 별도의 프로덕션 프로파일링 빌드에서 측정했다. 커밋 수와 각 회차 최대 `actualDuration`의 중앙값을 기록했다. [React Profiler](https://react.dev/reference/react/Profiler)
